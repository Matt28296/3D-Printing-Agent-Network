## Notes (do not block)

1. **No `M907 E430`.** The flattened stock profiles have an empty `print_settings_id`, so the stock `{if print_settings_id=~/.*QUALITY @MK3.*/}M907 E430` line in start_gcode (and the matching `M907 E538` reset in end_gcode) is skipped. The extruder motor runs at the firmware default current instead of the QUALITY preset's reduced one. Nothing was added, the start/end stay consistent, and it is not a safety issue; at most slightly warmer extruder motor / finer surface artefacts. Fix for later (toolsmith or user): keep the preset names in the profile files (or use user-exported profiles).
2. **Config-block differences are format only:** `start_gcode` differs only by `\"` escaping in the .ini; `thumbnails` 160x120 → 160x120/PNG; `gcode_label_objects` 1 → octoprint; legacy keys not written by PrusaSlicer 2.7.2 (`ensure_vertical_shell_thickness`, `external_fill_pattern` (now top/bottom_fill_pattern), `infill_only_where_needed`, `compatible_printers`, `renamed_from`, octoprint/serial host keys).
3. **Bed sheet:** `config/printer.json` lists only a smooth PEI sheet; PETG can bond too strongly to smooth PEI. Preflight should call for a release layer (glue stick or window cleaner).
4. **Outside this gate:** `design_review.md` is PASS but `strength.md` is `VERDICT: NEEDS_TEST` (proof test in spec §8). Whether that satisfies the DESIGN gate is the head-orchestrator's call; it does not change this G-code verdict.
