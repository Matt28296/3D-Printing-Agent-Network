## Notes (do not block)

1. **The window seam is on the tab-face edges.** The seam runs up the two edges where the window's ends meet the +y face. The servo case enters through those edges, with only 0.1 mm end clearance, and its tabs seat on that face. On the first plate, fit one MG90S through the window, notch and filed slit before printing plates 2–3 (DFM round 4 also asks for this). If the case is tight, lightly deburr those two edges.
2. **No `M907 E430`.** The flattened stock profiles have an empty `print_settings_id`, so the profile's `{if print_settings_id=~/.*QUALITY @MK3.*/}M907 E430` line is skipped, and so is the matching `M907 E538` at the end. The extruder runs at the firmware's default current, as in the arm jobs. Nothing was added and it is not a safety issue.
3. **Config differences are format only.** `thumbnails` 160x120 → 160x120/PNG; `gcode_label_objects` 1 → octoprint (labels as comments). Legacy keys PrusaSlicer 2.7.2 doesn't write: `ensure_vertical_shell_thickness`, `external_fill_pattern`, `infill_only_where_needed`, `compatible_printers`, `renamed_from`, octoprint/serial host keys.
4. **Bed:** the only sheet is smooth PEI (`config/printer.json`). PETG needs a glue-stick release layer there (DFM round 4); it is in preflight.md.
5. **`materials_on_hand` is empty** in `config/printer.json`. Spec §6 assumes PETG; preflight.md asks the user to confirm.
6. **Re-slicing changes the hash.** The comment header carries the slice time, so a local re-slice has a new sha256 and new estimates. `approve.py` re-validates whatever `part.gcode` is in the folder.
7. **Outside this gate:** strength is NEEDS_TEST (placeholder allowables, lowest SF 4.22). The proof test in spec §8 is for brackets printed from this 100 % plan.
