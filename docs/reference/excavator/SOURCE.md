# Source of this reference

`AssemblyExample.FCStd` is the excavator-arm example assembly from the FreeCAD project (https://www.freecad.org, https://github.com/FreeCAD/FreeCAD), made with FreeCAD's Assembly workbench. FreeCAD and its bundled example files are distributed under the GNU LGPL v2.1 or later. This copy is included unchanged as test data and as a worked example for `tools/import_fcstd.py`. All rights in the model belong to its original authors.

Everything else in this folder (`reference.md`, `reference.json`, `assembly.png`, `parts/`, `assembled/`) was generated from that file by `tools/import_fcstd.py`.
